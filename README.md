# MSP Technician App
### What does this app aim to do? It aims to be a all in one solution for IT Technicians.
Frameworks used: C# .NET 8.0, MVVM and WPF.
All Software Developement Lif Cycle managed through Github and Jira.

<ins>Current Features:</ins>
```
- Clone Disks in a live system using the built in windows VSS solutions
- Transfer User Profile Data to an external drive then the application disperses the information.
- Change Windows User Connection to type private to enable network sharing
- Transfer and Backup a list of saved XML files that store Wi-Fi passwords.
```
